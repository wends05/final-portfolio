# Portfolio

The owner's personal showcase site at portfolio.wends.dev (named wends.dev): projects, the skills they demonstrate, and a CV. Visitors confirm experience and stack quickly, then leave or go deeper.

## Language

**Project**:
A piece of the owner's work, shown on the site with its own case study.
_Avoid_: Work, entry

**Case study**:
The page for one project: its description, facts, credits, gallery, and a write-up of the problem, approach, and result.
_Avoid_: Project page, project detail

**Description**:
The one or two sentence summary of a project, shown in lists and link previews. The case study's longer write-up is separate.
_Avoid_: Summary, blurb

**Draft**:
A project or skill marked as not ready to show. It is hidden on the live site and appears only when drafts are switched on.
_Avoid_: Unpublished, hidden

**Featured project**:
A project chosen by hand, in a set order, for the homepage. The projects list shows featured projects first.
_Avoid_: Pinned project

**Skill**:
An area of the owner's work, such as Web development, with its own page, a confidence from 0 to 100, and the tools that belong to it.
_Avoid_: Category, skill category

**Top skill**:
A skill chosen by hand, in a set order, for the homepage.
_Avoid_: Featured skill

**Tool**:
A technology such as React, known by its name. A tool can belong to several skills or to none, and a project lists the tools it used.
_Avoid_: Technology, skill (in the old sense of a technology)

**Collaborator**:
A person credited on one or more projects. Collaborators do not sign in.
_Avoid_: Contributor

**Credit**:
One collaborator's appearance on one project, with an optional role.
_Avoid_: Attribution

**Agent copy**:
A page as Markdown, for agents: `/projects/<slug>.md` for `/projects/<slug>`, `/index.md` for the home page. Built from the same content as the page; drafts have none.
_Avoid_: Markdown version, machine copy

**Agent view**:
A page's agent copy rendered for people, under `/ai`: `/ai/projects/<slug>`. The Human / Machine toggle moves between a page and its agent view.
_Avoid_: Machine view, AI page
