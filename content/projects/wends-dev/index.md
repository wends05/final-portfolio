This project was long overdue. My original goal was to create this early during university, and for each project that I want to showcase, I update the content over time. But I ended up doing it on the last year of university, where I can actually have projects and skills that I can display in public.

The state of AI (from my own knowledge), lies on adapting the SDLC for making softwares with AI integrated workflows. This includes use of AI agents to automate repetitive tasks such as committing, pushing, and merging. I also adapted use of AI for code review in PRs.

One of the goals of this application is to apply this AI-SDLC approach as well as SDD (Spec Driven Development) to practice applying AI in developing softwares. This is done through the Plan-Execute-Validate loop as written in the [AGENTS.md](https://github.com/wends05/final-portfolio/blob/main/AGENTS.md) file. If you look at the [repository](https://github.com/wends05/final-portfolio), I also have claude commit some of the features / changes as well as let an agent review the code, fix or inform me through the conversations, and tell me to merge if CI is already okay.

Aside from the code changes, PRs also contain a Linear issue that is automatically linked to the PR, hence connecting a certain PR to specific issue/s. This also allows me to practice integrating AI into Project Management workflows.

Despite letting AI do some of the changes, I still ensure I have the full control over the codebase, architecture, and important decisions that needs to be made. Although this may be too much for a solo application, I want to ensure that my vision for this portfolio website is actually realized.
